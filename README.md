# Artale 拍賣行價格追蹤

楓之谷 Artale 拍賣行價格紀錄工具：自動偵測遊戲視窗、用 OCR 擷取拍賣行成交價，依道具名稱自動歸類到 `config.yaml` 設定的商品，累積成每日 OHLC 並產生 K 線圖；有設定官方價格的商品，另可比較「官方 WC 管道」與「拍賣行」哪個取得方式比較划算。可同時追蹤多個商品（例如突襲額外獎勵票券、SP初始化卷…），各自分開存放、分開看圖。

> 僅供個人參考，價格走勢不代表未來。擷取時腳本會自動操作遊戲視窗（點擊、按 Enter），請自行評估是否符合遊戲規範。

## 功能

| 啟動檔 | 功能 |
|---|---|
| `run_scrape.bat` | 偵測遊戲視窗 → 更新頁面 → 自動翻 20 頁 → OCR 讀出日期時間與單位價格 → 輸出 Excel |
| `run_from_img.bat` | 選一個資料夾（內含既有的 `page_*.png` 頁面截圖），不碰遊戲視窗，直接重新 OCR 輸出 Excel |
| `run_import.bat` | 選資料夾，把當天的時段 Excel 合併成 OHLC Excel，確認後匯入資料庫 |
| `run_chart.bat` | 選商品，看近一週／近一個月／全部的 K 線圖，附每日數據表 |
| `run_compare.bat` | 選有設定官方價格的商品，輸入買幣價，比較官方管道與拍賣行的成本 |
| `run_craft_calc.bat` | 選武器，填每個材料單價與現成武器價格，算製作費用與盈餘 |

### 特色
- **視窗偵測**：以視窗標題找到遊戲，擷取客戶區指定範圍（作法參考 [MapleStory-Worlds-Artale-](https://github.com/gitjohnishandsome/MapleStory-Worlds-Artale-)），並加上 OCR。
- **失敗就停止**：每一頁都讀頁碼「N / M」驗證；更新後不在第 1 頁、翻頁失敗、跳頁、不是市價分頁、畫面與上一頁相同、道具名稱判定不出商品，都會立刻停止且不產生 Excel。
- **多商品**：依 OCR 讀到的「道具名稱」自動比對 `config.yaml` 的 `items` 清單，分開存放成 `data/<商品>/<日期>/`，資料庫與圖表都以商品為單位分開。
- **資料庫只存每個商品每天的開高低收**（SQLite）。只接受檔名含 `OHLC` 的 Excel；日期或商品重複／混雜會跳出提醒或標紅拒絕。
- **K 線圖**：價格以「萬」顯示、缺漏日期留空、資料可能不完整的日子標 ⚠、有設定官方價格的商品可疊官方等值線、圖下附可排序的每日數據表。漲紅跌綠。

## 安裝

需要 Windows 與 Python 3.9+。

```
pip install -r requirements.txt
```

## 快速開始

1. 開啟遊戲，進入拍賣行的「市價」分頁，搜尋想追蹤的商品（例如「突襲」）。
2. 雙擊 `run_scrape.bat` 抓取價格。程式會依道具名稱自動判定商品，產生 `data/<商品>/日期/scrape_*.xlsx`。建議每天抓幾次，例如 09:00、12:00、18:00、24:00。
3. 一天結束後雙擊 `run_import.bat`：選當天該商品的資料夾 → 檢查預覽 → 匯出 OHLC Excel → 匯入資料庫。
4. 雙擊 `run_chart.bat`，選商品看 K 線圖。

要追蹤新商品，先在遊戲裡搜尋該商品確認會出現在拍賣行，再到 `config.yaml` 的 `items` 清單加一筆（商品全名 + 比對關鍵字），之後雙擊 `run_scrape.bat` 就會自動歸類。

視窗座標（表格範圍、下一頁按鈕、搜尋框、頁碼）在 `config.yaml`，預設是 1280×720 的視窗；更換大小請用 `python capture.py --calibrate` 重新校準。

完整說明見 [操作說明書.md](操作說明書.md)。

## OHLC 規則

- 開盤價：當天最接近 9:00 的那筆；收盤價：當天最接近 24:00（午夜）的那筆（時間差相同取最低價）。
- 最高價／最低價：當天資料中最高／最低的單位價格。

## 多商品設定

`config.yaml` 的 `items` 是追蹤的商品清單，每筆：
- `name`：商品全名，也是資料夾、檔名、資料庫裡的識別碼。
- `match`：比對 OCR 讀到的「道具名稱」用的關鍵字（子字串即可）。
- `official_price_twd` / `official_tickets`（選填）：官方管道成本，設定了才會出現在「取得方式比較」。

擷取完成後，程式統計這次讀到的道具名稱比對到哪個商品；比對不到（新商品還沒加進清單）或同時比對到多個商品（檔案混了不同商品、或 `match` 關鍵字彼此重疊），都會直接停止，不會猜測硬塞。

## 取得方式比較

只有設定了 `official_price_twd`／`official_tickets` 的商品才能比較（預設突襲額外獎勵票券：NT$1,990 買 77 張）。輸入「1 億楓幣 = NT$ 多少」，程式換算 m = 官方總價 ÷ 買幣價（相當於多少億楓幣），再與拍賣單價比較，並標出較划算的一方。

## 專案結構

```
capture.py      視窗偵測與擷取
catalog.py      商品清單：比對道具名稱決定商品
ocr.py          OCR 解析（RapidOCR）
scrape.py       自動翻頁擷取 + 驗證
from_img.py     從既有截圖重新 OCR（不需遊戲視窗）
store.py        合併 Excel、計算 OHLC
db.py           SQLite（每商品每日 OHLC）
import_gui.py   資料匯入視窗
chart.py        K 線圖與數據表
chart_gui.py    K 線圖視窗
compare.py      官方管道 vs 拍賣行
compare_gui.py  比較視窗
config.yaml     座標、設定與商品清單
```

## 注意

- `data/`（資料庫、Excel、截圖）不會被版本控制；截圖內含角色名稱與楓幣餘額，請勿公開。
- OCR 在不同解析度或遊戲改版後可能需要重新校準。
